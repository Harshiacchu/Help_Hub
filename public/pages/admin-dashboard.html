Getting started
  1. Configuration: check your company name and support email. Ticket categories and priorities come from your company's prompt file.
  2. Team: generate a share code for each agent, admin or customer and send them the invite link.
  3. API Keys: create a key so your other systems can open tickets using the X-API-Key header.
  4. Dashboard and Analytics: track ticket counts, response times and resolution times as tickets come in.
