🎯 FEATURE 2: USER AUTHENTICATION (Login/Register/Logout)
================================================================================

USER FLOW - REGISTER:
1. Agent visits register.html with share code
2. Fills in: Email, Password, Name, Share Code
3. Submits form → POST /api/v1/auth/register
4. Backend validates share code → creates user
5. Redirects to login.html

USER FLOW - LOGIN:
1. User visits login.html
2. Fills in: Email, Password
3. Submits form → POST /api/v1/auth/login
4. Backend validates password → creates session
5. Redirects to dashboard (role-dependent)

USER FLOW - LOGOUT:
1. User clicks logout
2. POST /api/v1/auth/logout
3. Session destroyed
4. Redirect to login.html
